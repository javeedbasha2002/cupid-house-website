# Cupid House website starter

A responsive, multi-page café website built as a reusable starter. This version is tailored to Cupid House Rooftop Taproom & Kitchen using the logo and venue photographs supplied for the project.

## Pages

- `index.html` — home and venue highlights
- `menu.html` — handoff page for the WaitrPOS customer app and QR destination
- `story.html` — rooftop and interiors
- `journal.html` — blog/article index
- `journal-post-template.html` — copy this file to create a post
- `visit.html` — address and directions

Shared typography, layouts, responsive behavior and theme colors live in `styles.css`. To adapt the starter for another venue, replace the images in `assets/`, update the visible venue copy and address on each page, then adjust the CSS custom properties near the top of `styles.css` to match its palette and ambience. Keep that café's real interior photography in the page gallery.

- Set up the final website domain before adding canonical URLs, a production sitemap, and the Google Search Console property.

Food and cocktail reference photography appears on the landing page's picture board. The high-resolution Cupid House logo is used throughout the header, menu handoff page, and footer.

The QR image is generated by QuickChart's QR endpoint. Before the WaitrPOS URL is configured it points to the site's menu handoff page; after configuration it points directly to the public customer app. The QR image request contains that public URL. See [QuickChart QR documentation](https://quickchart.io/documentation/qr-codes/).

The public address provided for Cupid House is used on the visit page, with a Google Maps directions link. The footer includes “Powered by WaitrPOS” on every page.

## Publishing a journal article

This is a static HTML site; it does not have a sign-in dashboard for blog uploads. To publish an article:

1. Copy `journal-post-template.html` to a descriptive filename, for example `best-rooftop-dinner-puducherry.html`.
2. Replace every `REPLACE` / `YYYY-MM-DD` value: browser title, meta description, headline, byline/date, article text, image URL and alt text, Open Graph tags, and BlogPosting data. Remove the `noindex` line from the copied article.
3. Put the article's own photo in `assets/journal/` and use a descriptive filename.
4. Add a linked article card to `journal.html`, then remove the “No posts yet” message.
5. Upload the changed files and image to the website host, or publish the updated site through its deployment workflow.

For direct writing and image uploads through a dashboard, connect a CMS. That requires choosing a CMS and the final hosting setup; neither is configured yet.

## Search visibility

Each page has its own title and description. The home page also includes Restaurant structured data using the address supplied for Cupid House. Before launch, add the final domain to canonical links, Open Graph image URLs, and a sitemap; verify the domain in Google Search Console and submit the sitemap. Write useful, accurate articles with clear headings and links to the visit and menu pages. Search engines control when pages are crawled and how results appear.
